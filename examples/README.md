# Synthetic example data

All files in this directory are fabricated and intended for tests and documentation. They do not contain company data, real antibody sequences, personal information, or API keys. Some examples are used by the local pilot workflows.

| File | Intended scenario |
| --- | --- |
| `generic_grouped_normal.csv` | Normal generic grouped observations |
| `generic_grouped_missing.csv` | Missing-value alert |
| `generic_grouped_high_cv.csv` | High replicate variability alert |
| `elisa_standard_curve_normal.csv` | In-range synthetic ELISA standards and samples |
| `elisa_out_of_range.csv` | Synthetic unknown response outside the standard range |
| `phase3b_inverse_boundary.csv` | Synthetic increasing 4PL standards with one in-span, one below-span, and one above-span sample response |
| `elisa_curve_unfit.csv` | Non-monotonic synthetic responses that should be unsuitable for fitting |
| `columns_messy.csv` | Whitespace, casing, and punctuation in headers |
| `empty_file_placeholder.txt` | Explanation for an empty-file fixture; no binary corrupt file is included |

The field definitions are in `templates/DATA_DICTIONARY.md`. XLSX templates are generated by `scripts/generate_xlsx_templates.py`.
