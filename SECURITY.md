# Security policy

## Scope

BioLab Copilot is a local-first research-use pilot. It is designed to process user-selected
files on the local machine and to preserve source hashes, configuration, warnings, and output
provenance. It does not provide authentication, multi-user isolation, cloud storage, telemetry,
or a public network service.

## Reporting a vulnerability

Do not open a public issue containing credentials, private data, patient information, real
antibody sequences, or a working exploit. Once this repository is published, use GitHub's private
Security Advisory mechanism when available. Until then, provide a minimal non-sensitive
description to the project owner through the repository's private communication channel.

Please include the affected version or commit, a minimal reproduction using synthetic data, and
the security impact. Do not attach user uploads, generated reports, `.env` files, API keys,
tokens, or other secrets.

## Release security expectations

- Source data must remain outside Git and must never be used in examples or tests.
- CI uses synthetic fixtures and does not upload outputs or reports.
- The UI binds to `127.0.0.1`, disables public sharing and analytics, and limits downloads to
  the current session directory.
- Reports are generated by declared Python dependencies without Node, artifact-tool, hidden
  executables, or runtime subprocesses.
- Research-only ELISA inverse estimates must not be presented as validated quantification.
